## 2023-10-27 - Dialog Triggers Missing Explicit ARIA Labels
**Learning:** In the `ImageLightbox` component, the trigger button wrapped the image and relied on the child image's `alt` attribute for screen reader context. However, for a button that opens a dialog (`aria-haspopup="dialog"`), an explicit `aria-label` describing the *action* (e.g., "Enlarge image: [alt text]") is more accessible and informative than just reading the image description.
**Action:** When creating trigger buttons for modals, dialogs, or enlarged views that wrap media, always add an explicit `aria-label` describing the action (e.g., "Enlarge image", "View full screen") and ensure proper keyboard focus styling (`focus-visible:ring-accent-gold/50`) so keyboard users can clearly see when they've tabbed to the interactive element.
