## 2026-08-26 - Image Lightbox Trigger Button ARIA Label and Accessible Name Overriding
**Learning:** Adding a generic `aria-label` (e.g., "Enlarge image") to a `<button>` that wraps an image causes screen readers to completely ignore the image's `alt` text. This destroys context, making the user hear "Enlarge image, button" without knowing what the image is. Any decorative child icons (like `Maximize2`) within the button must also have `aria-hidden="true"` to prevent needless announcements.
**Action:** When adding an `aria-label` to a button that wraps contextual content (like an image), the label *must* incorporate that content to preserve context (e.g., `` aria-label={`Enlarge image: ${alt}`} ``), and supplementary decorative icons should be hidden with `aria-hidden="true"`.
