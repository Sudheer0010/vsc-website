## 2025-03-09 - Accessible Lightbox Trigger Context
**Learning:** When using an image wrapped in a button as a trigger (e.g. for an Image Lightbox), screen readers will by default read out the child image's `alt` text. However, this fails to communicate the *action* that the button performs. Wrapping purely decorative icons (like a magnifying glass) in an `aria-hidden="true"` span and adding a descriptive `aria-label` to the main button (e.g., ``aria-label={`Enlarge image: ${alt}`}``) significantly improves context for assistive technologies without disrupting the visual layout.
**Action:** Always add an action-oriented `aria-label` to interactive triggers that wrap content, and explicitly hide decorative child icons with `aria-hidden="true"` to prevent screen reader clutter.
