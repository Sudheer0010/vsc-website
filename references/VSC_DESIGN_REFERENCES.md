# VSC Design References

This file does not define a design system. It is an index of approved external
references pulled from `references/awesome-design-md/` and what, specifically,
each one is approved for.

**`DESIGN_PRINCIPLES.md` at the project root is always authoritative.** External
references are pattern inspiration only and must never override VSC's palette,
typography, motif system, or composition rules. If a pattern below conflicts
with `DESIGN_PRINCIPLES.md` in any way, `DESIGN_PRINCIPLES.md` wins — full stop,
no exceptions, no "just this once."

---

## 1. Mintlify

**Approved for:**
- Long-form reading layouts
- Prose width / measure
- TOC / sidebar active states
- Documentation-style navigation

Source: `references/awesome-design-md/design-md/mintlify/DESIGN.md`

## 2. IBM / Carbon

**Approved for:**
- Institutional restraint
- Accent scarcity
- Flat hierarchy
- Border-led data surfaces

Source: `references/awesome-design-md/design-md/ibm/DESIGN.md`

## 3. Mastercard

**Approved for:**
- Validation only — confirms a warm-paper canvas can read as institutional and
  editorial at once. Not a source of new patterns.

Source: `references/awesome-design-md/design-md/mastercard/DESIGN.md`

## 4. Stripe

**Approved for:**
- Tabular numerals / financial-data presentation patterns only

**Do not borrow:** its overall visual language (gradient-mesh heroes, thin
display type, indigo/navy palette).

Source: `references/awesome-design-md/design-md/stripe/DESIGN.md`

## 5. Linear

**Approved for:**
- Focus states
- Strict accent-role discipline

**Do not borrow:** its dark theme.

Source: `references/awesome-design-md/design-md/linear.app/DESIGN.md`
