# VSC Component Library Specification (Phase II Specs)

> **Design Objective**: Every component must be unmistakably VSC, built with handcrafted craftsmanship rather than generic web component primitives.

---

## Component Catalog

| Component Name | Visual Signature | Purpose |
| :--- | :--- | :--- |
| **`ResearchLine`** | Hairline gold rule (`#C9A84C`) drawing left-to-right (0.8s) | Precedes every major research document (`R-01` to `R-06`). |
| **`SpotlightNavbar`** | Watch-bezel glass capsule (`#0C101E/72`), active item ambience glow | Primary fixed desktop & mobile navigation capsule. |
| **`EditorialHeading`** | *Cormorant Garamond* serif headline (44px–88px), leading-[1.05] | High-impact thesis entrance statements. |
| **`ReflectionBlock`** | Large serif question quote (`28px`), muted gold indicator dot | Concludes every research document chapter. |
| **`AcademicMarginNote`** | *DM Mono* subtext (11px) aligned in right margin with hairline rule | Side commentary and structural market signal annotations. |
| **`ResearchCard`** | `#0B0F1E` elevated paper surface, subtle border, metadata date rule | Publication-grade container for Market Letters and research. |
| **`FrameworkMatrix`** | 2-column contrast panel comparing Mutual Funds vs. VSC | High-clarity institutional comparison table. |
| **`InstitutionalForm`** | Tinted `#090D18` panel, underlined inputs, compliance disclaimer | Strategic discussion inquiry interface. |
| **`InstitutionalFooter`** | 2-column publication footer, micro-mono regulatory footnotes | Formal fund prospectus footnote footer. |
