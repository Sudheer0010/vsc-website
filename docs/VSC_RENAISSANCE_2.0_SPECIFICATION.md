3. **Module 2 (Why VSC Exists)**: Full-width giant serif manifesto line with zero box boundaries (*“Most investors don't need more information. They need a better process.”*) + academic margin note commentary on the right.
4. **Module 3 (How We Think)**: 50% Visual Attention Rule 01 Hero Card (`Protect Capital First`) + Lucide stroke-only `Shield` icon + sub-3s horizontal 3-column briefing grid.
